# Responsive Web Design (RWD) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Support the application from a 320px mobile viewport to desktop with a consistent five-item mobile navigation and accessible More sheet.

**Architecture:** Preserve the desktop sidebar from 901px upward. A Razor partial owns tablet/mobile navigation and the native dialog. One shared JavaScript controller owns More behavior. `dashboard.css` owns shell rules; the page CSS files only adjust content layout.

**Tech Stack:** ASP.NET Core MVC Razor, native HTML dialog, CSS media queries/safe-area variables, browser DOM APIs, Node built-in test runner.

- [ ] **Step 3: Add `wwwroot/js/mobile-navigation.mjs`**

```javascript
export const isMoreSection = (section) => section === 'category' || section === 'tag';
export function createMoreSheetController({ trigger, dialog, close }) {
  const sync = () => trigger.setAttribute('aria-expanded', String(dialog.open));
  const closeSheet = () => { if (dialog.open) dialog.close(); };
  const open = () => { if (!dialog.open) dialog.showModal(); sync(); close.focus(); };
  trigger.addEventListener('click', open);
  close.addEventListener('click', closeSheet);
  dialog.addEventListener('click', (event) => { if (event.target === dialog) closeSheet(); });
  dialog.addEventListener('close', () => { sync(); trigger.focus(); });
  sync();
  return { open, close: closeSheet };
}
```

Create `wwwroot/js/mobile-navigation.js` that selects `[data-more-trigger]`, `[data-more-sheet]`, and `[data-more-close]`, then calls `createMoreSheetController` only when all three exist. Native dialog behavior supplies Escape and focus containment; do not add a polyfill or another logout handler.
